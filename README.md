## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/THUAS-ACS15/A-maze-ing-Delft
   ```
2. Go to the project folder:
   ```bash
   cd A-maze-ing-Delft
   ```
3. Run the project:
   ```bash
   docker compose run --build --rm app   
   ```
